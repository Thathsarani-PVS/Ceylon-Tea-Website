📌 Overview

Ceylon Tea is a feature-rich, full-stack e-commerce web application designed to bridge the gap between premium Sri Lankan tea producers and global tea enthusiasts. Built with a modern monolithic architecture using Pure PHP (PDO) and MySQL, the platform offers a seamless, secure, and intuitive shopping experience tailored for specialized product trading.


---
## 🛠️ Tech Stack

* **Front-End:** HTML5, CSS3, JavaScript (ES6+), AJAX
* **Back-End:** Pure PHP (PDO)
* **Database:** MySQL (Relational DB Design, Normalized up to 3NF)
* **Tools & Server:** XAMPP, Apache, phpMyAdmin, Git


---

## ✨ Key Features & Functionalities

* **Dynamic Product Catalog:** Categorized listing of premium tea variants (Organic, Green, Flavored) with dynamic filtering, ratings, and image galleries.
* **User & Vendor Authentication:** Secure registration and login portals for customers and vendors[cite: 1].
* **Asynchronous Wishlist (AJAX Toggle Logic):** Instant addition and removal of favorite products without page refreshes, handled via backend PHP handlers[cite: 1].
* **Algorithmic Order Generation:** Custom order tracking mechanism (`ORD-YYYYMMDD-HEX`) combining date stamps and cryptographic strings for enhanced privacy and business confidentiality[cite: 1].
* **Secure Shopping Cart & Checkout:** End-to-end shopping journey from cart management to order placement[cite: 1].

---

## 🔒 Advanced Security & Architecture

* **SQL Injection Prevention:** Utilizes **PDO Prepared Statements** for all database queries[cite: 1].
* **Credential Hashing:** Secured customer and vendor passwords using PHP’s `password_hash()` with modern **BCrypt** algorithms[cite: 1].
* **Resilient Database Design:** Structured with primary/foreign keys and junction tables for Many-to-Many relationships, featuring `LEFT JOIN` queries to gracefully handle missing media assets[cite: 1].
